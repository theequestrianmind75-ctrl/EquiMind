<product_requirements>
EquiMind is a mental performance mobile app designed for equestrians. Its core function is to provide a library of Rider Tools—mental strategies and exercises—to help riders manage their emotional state before and during rides.

**Core Features:**
*   **Rider Tools Library:** A categorized collection of over 100 mental strategies with detailed instructions.
*   **Admin Text Editor:** A password-protected web page () allowing the user to efficiently perform bulk edits on all tool content in a single text area.
*   **Pre-Ride Assessment:** A feature (partially implemented) to assess the rider and horse's state to suggest relevant tools.
*   **User Authentication:** A standard JWT-based system for login and registration.

**Development Context:**
The initial project involved restoring a lost library of tools and fixing data corruption. The work then shifted to making the application robust for production. This included creating an automatic database restore mechanism to handle the ephemeral nature of the development environment and to ensure data is present upon deployment. The most recent focus has been on debugging production deployment failures to provide the user with a stable editing environment.
</product_requirements>
